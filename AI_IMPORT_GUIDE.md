# Работа с нейросетью: от выгрузки до загрузки обратно

## Как устроен круг

```
Грамотаград → Экспорт .xlsx → чат нейросети → CSV-блоки в ответе
     ↑                                               ↓
     └──── Импорт .xlsx ←── csv-to-xlsx.mjs ────────┘
```

Нейросеть в чате **не умеет отдавать бинарный .xlsx**, поэтому она пишет
текстовые CSV-блоки, а файл собирает скрипт. Это же избавляет от возни с
кодировками и разделителями, на которых обычно спотыкается Excel.

---

## 1. Промпт для чата

Приложите к сообщению файл выгрузки и вставьте текст ниже целиком.

```text
Ты готовишь данные для загрузки в школьное приложение «Грамотаград».
К сообщению приложен файл выгрузки из этого приложения.

СНАЧАЛА изучи приложенный файл. Листы «Ученики», «Классы», «Предметы»,
«Педагоги» — это справочники. Все имена, которые ты используешь в ответе,
бери ТОЛЬКО оттуда, посимвольно. Ничего не придумывай и не исправляй.

ФОРМАТ ОТВЕТА
Содержательную часть (анализ, письма родителям, отчёт собственнику)
пиши свободно. Но данные для загрузки оформляй отдельными блоками кода,
по одному на лист, и ОБЯЗАТЕЛЬНО подписывай блок именем листа:

Файл: Рекомендации.csv
```csv
Ученик,Класс,Текст
Кузнецов Егор,1А,"Читать вслух по 15 минут в день, вести дневник чтения."
```

Разделитель — запятая. Поля с запятыми, кавычками или переносами строк
бери в двойные кавычки. Кавычку внутри поля удваивай. Кодировка UTF-8.
Заголовки — ровно как в таблицах ниже, без изменений и перестановок.

ДОПУСТИМЫЕ ЛИСТЫ И КОЛОНКИ

Рекомендации.csv
  Ученик | Класс | Текст
  Текст — одна связная рекомендация, 1–3 предложения, без списков и
  переносов строк.

Ученики.csv   (добавление новых учеников)
  ФИО | Класс

Педагоги.csv  (добавление новых педагогов)
  Фамилия | Имя Отчество | ФИО | Роль | Пароль | Воспитатель
  Роль — строго «учитель» или «админ».
  Пароль — не короче 8 символов, придумай стойкий, по одному на человека.
  Воспитатель — «да» или «нет».
  ФИО должно совпадать со склейкой «Фамилия» + пробел + «Имя Отчество».

Классы.csv
  Название

Предметы.csv
  Название

Оценки.csv
  Ученик | Класс | Предмет | Дата | Оценка | Комментарий
  Дата — строго ГГГГ-ММ-ДД, например 2026-10-06.
  Оценка — только один из символов: 5, 4, 3, 2, Н. «Н» значит
  «не было на уроке». Других значений не существует.
  Предмет — точное название из листа «Предметы».

ЖЁСТКИЕ ПРАВИЛА

1. Колонка «Класс» обязательна везде, где она есть в таблице выше.
   В школе есть полные тёзки в разных классах, и ученик опознаётся
   ТОЛЬКО парой «ФИО + класс». Ошибка в классе — рекомендация уйдёт
   чужому ребёнку.
2. ФИО ученика копируй из листа «Ученики» побуквенно: та же буква ё,
   тот же регистр, один пробел между словами. Не переставляй имя и
   фамилию, не сокращай, не добавляй отчество, если его нет в выгрузке.
3. Название класса бери из колонки className (например 1А, 2Б) —
   русская буква, без пробела. Никогда не пиши в этой колонке одно
   голое число: оно будет понято как внутренний номер записи, а не имя.
4. На одного ученика — НЕ БОЛЕЕ ОДНОЙ строки в «Рекомендации.csv».
   Загрузка делает новую рекомендацию текущей и снимает отметку со
   старой, поэтому из нескольких строк подряд выживет только последняя.
5. Не добавляй колонки id, createdAt и любые служебные: нумерация
   назначается приложением сама.
6. Не создавай листы «Уроки» и «Логи» — загрузка их не читает.
7. Если нужного ученика, класса или предмета нет в выгрузке — не
   выдумывай строку. Вынеси её отдельным списком «Требует внимания»
   обычным текстом, вне блоков CSV.
8. Если данных для какого-то листа нет, просто не создавай этот блок.

В конце ответа одной строкой подведи итог: сколько строк в каждом
созданном CSV.
```

## 2. Что делает админ с ответом

1. Каждый блок `csv` сохранить в файл **с именем листа**: текст блока,
   подписанного `Рекомендации.csv`, кладём в файл `Рекомендации.csv`.
   Имя файла определяет имя листа — переименование сломает загрузку.
2. Собрать книгу и сразу проверить её по свежей выгрузке:

```bash
node scripts/csv-to-xlsx.mjs Рекомендации.csv -o import.xlsx \
  --check gramotagrad-export-2026-10-06.xlsx
```

Несколько листов — просто перечислить файлы:

```bash
node scripts/csv-to-xlsx.mjs Рекомендации.csv Ученики.csv Оценки.csv \
  -o import.xlsx --check gramotagrad-export-2026-10-06.xlsx
```

`--check` сверяет строки со справочниками и заранее показывает, что
загрузка отвергнет:

```
Рекомендации строка 5: ученика «Петров Несуществующий» нет в классе 1А
Рекомендации строка 6: класса «9Я» нет в базе
Рекомендации строка 7: повтор ученика (строка 2): останется только последняя
⚠ Проблемных строк: 3. Импорт их пропустит.
```

3. Исправить замечания (обычно — попросить чат переписать строку) и
   собрать заново, пока не будет `✓ Проблем не найдено`.
4. Загрузить `import.xlsx` в приложении: **Админ → Импорт/Экспорт**.
   Приложение покажет отчёт по каждому листу: принято, пропущено,
   ошибки с номерами строк.

## 3. Справочник: что читает загрузка

Загрузка обрабатывает **шесть** листов. Имена листов обязаны совпадать
побуквенно, иначе лист молча пропускается.

| Лист | Обязательные колонки | Необязательные |
|---|---|---|
| `Ученики` | ФИО, Класс | — |
| `Педагоги` | Фамилия, Имя Отчество, ФИО, Пароль | Роль, Воспитатель |
| `Классы` | Название | — |
| `Предметы` | Название | — |
| `Оценки` | Ученик, Класс, Предмет, Дата, Оценка | Комментарий |
| `Рекомендации` | Ученик, Класс, Текст | — |

Синонимы заголовков (загрузка берёт первый непустой):

- Ученик = `Ученик` / `ФИО ученика` / `studentName`
- Класс = `Класс` / `className` (в «Учениках» ещё `classId`)
- Текст = `Текст` / `Рекомендация` / `text`
- Дата = `Дата` / `lessonDate`
- Оценка = `Оценка` / `value`
- Название = `Название` / `Номер` / `name`

Благодаря синонимам выгрузка импортируется обратно без переименования
столбцов — кроме листа «Педагоги», см. ловушку №2.

## 4. Ловушки, проверенные на коде

**1. Тёзки.** В текущей базе 20 учеников из 40 имеют полного тёзку в
другом классе — например «Кузнецов Егор» есть и в 1А, и в 3В. Ученик
ищется по паре ФИО+класс, поэтому колонка «Класс» это не украшение, а
часть идентификатора.

**2. Выгрузка не загружается обратно целиком.** В листе «Педагоги»
выгрузки нет колонки «Пароль» (хеши наружу не отдаются), а загрузка
требует пароль не короче 8 символов. Все педагоги будут пропущены с
ошибкой. Это защита: раньше тут стоял общий пароль по умолчанию, и при
повторной загрузке все учётные записи, включая админские, получали
один известный пароль.

**3. Рекомендация всегда становится текущей.** Колонка `isCurrent` из
выгрузки при загрузке игнорируется: новая запись делается актуальной, а
прежняя уходит в архив. Поэтому две строки на одного ученика в одном
файле — это не две рекомендации, а потеря первой.

**4. Голое число в колонке «Класс»** понимается как внутренний номер
записи, а не как название. Сейчас классы называются 1А…5Д, так что
проблемы нет, но если однажды появится класс с именем «5» — колонку
нужно будет заполнять через `className`.

**5. Оценки создают уроки.** Строка в «Оценках» при необходимости
заводит урок на эту дату, класс и предмет, и автором урока становится
тот админ, который загружает файл. Тема и домашнее задание остаются
пустыми — их заполняет учитель в журнале.

**6. Загрузка только добавляет.** Режим «заменить» отключён намеренно:
он стирал все данные школы вместе с сессией самого админа. Повторная
загрузка того же файла не задвоит учеников и педагогов — они будут
пропущены как дубли; оценка за ту же дату/предмет перезапишется.

**7. Новый педагог ничего не видит до назначения.** Загрузка заводит
учётную запись, но не выдаёт доступ к классам и предметам — это
делается вручную в **Админ → Назначения**. Без назначений учитель не
сможет открыть журнал.

**8. Ограничения файла:** только `.xlsx`/`.xls`, не больше 5 МБ,
загружать может только администратор.

## 5. Проверка инструментов

Конвертер проверен сквозным прогоном: сгенерированный `.xlsx` читается
библиотекой SheetJS — той же, что стоит в приложении, — и её разбор
колонок совпадает с тем, что увидит загрузчик. Предполётная проверка
поймала все подставленные ошибки: несуществующего ученика,
несуществующий класс, дату `06.10.2026`, оценку «отл», отсутствующий
предмет и повтор ученика.
